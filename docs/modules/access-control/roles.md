# Role dan izin

Halaman `/settings/roles` berada di menu **Pengaturan > Hak Akses > Role dan Izin**. Admin workspace dapat mengaktifkan atau menonaktifkan permission fitur untuk role `member` pada workspace aktif.

Role `admin` tetap memegang permission pengelolaan workspace dan akses agar tidak terkunci. Permission katalog/menu global platform tidak tersedia pada daftar izin tenant. Semua perubahan tetap divalidasi backend melalui permission `access-control.roles.manage`.
